# ☕ Cafeteria Bela Ciao

> Landing page desenvolvida para uma cafeteria fictícia, apresentando um ambiente aconchegante, cardápio de bebidas e alimentos, além de uma interface moderna e responsiva.

# 📖 Sobre o Projeto

O **Cafeteria Bela Ciao** é um site institucional criado para representar uma cafeteria moderna, proporcionando uma experiência agradável aos visitantes.

O projeto apresenta informações sobre a cafeteria, seus produtos, ambiente e diferenciais, utilizando um design limpo e elegante.

---

# ✨ Funcionalidades

- ☕ Página inicial moderna
- 🥐 Exibição dos principais produtos
- 📖 Seção "Sobre Nós"
- 📱 Layout responsivo
- 🎨 Interface elegante
- 🖼️ Imagens ilustrativas dos produtos
- 📍 Estrutura pronta para incluir localização e contato

---

# 🚀 Como Executar

## 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/cafeteria-bela-ciao.git
```

---

## 2. Entre na pasta

```bash
cd cafeteria-bela-ciao
```

---

## 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

ou utilize a extensão **Live Server** do Visual Studio Code para visualizar o site.
